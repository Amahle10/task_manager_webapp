# Full-Stack Task Manager

A simple full-stack task management application with a **FastAPI** backend (SQLite + SQLAlchemy) and a **React** frontend (Vite + Tailwind CSS).

## Setup Instructions

### Backend
1. Navigate to `backend/`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the server: `uvicorn main:app --reload`
4. The API documentation will be available at `http://120.0.0`.

### Frontend
1. Navigate to `frontend/`
2. Install packages: `npm install`
3. Run the development environment: `npm run dev`
